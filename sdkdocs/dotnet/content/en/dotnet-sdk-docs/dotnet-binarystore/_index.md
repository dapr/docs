The Dapr Binary Store package lets .NET applications store, retrieve, stream, and delete binary files in a configured Dapr binary store component. It supports stream-based uploads and downloads for large files, as well as byte-array access for files that fit in memory. A source generator can also create a strongly typed client bound to a specific store.

To get started, follow the [Dapr Binary Store how-to guide]({{% ref dotnet-binarystore-howto.md %}}) and refer to the [client usage guidance]({{% ref dotnet-binarystore-client-usage.md %}}) for configuration, streaming, and error handling.

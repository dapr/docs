Dapr provides several capabilities and tools for developing and debugging applications on your own machine, including IDE integrations, running multiple applications with a single command, and the [Dapr Dev Dashboard]({{% ref dapr-dev-dashboard.md %}}) for inspecting the Dapr applications running locally.
